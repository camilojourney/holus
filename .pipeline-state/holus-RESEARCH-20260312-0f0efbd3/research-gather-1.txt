#### 2. Best practices for AI content quality evaluation beyond engagement metrics
*   **Finding:** "LLM-as-a-judge" methodologies rely on structured rubrics instead of simple 1-5 scales. Best practices include breaking down subjectivity into measurable dimensions (Correctness, Tone, Safety), using binary/categorical scales, and providing "Golden Examples" (few-shot prompting) to anchor the judge.
    *   **Source URL:** https://github.com/confident-ai/deepeval (DeepEval Framework)
    *   **Date:** Undated
    *   **Confidence:** HIGH (Open-source framework documentation)
    *   **Specifics:** Framework implements "G-Eval" for LLM scoring based on custom rubrics.

*   **Finding:** Enforcing Chain-of-Thought (CoT) reasoning before scoring improves the accuracy of LLM judges. The judge must output a critique or reasoning step before assigning the final grade.
    *   **Source URL:** https://github.com/DataArcTech/LLM-as-a-Judge
    *   **Date:** Undated
    *   **Confidence:** HIGH (Research/Repository)
    *   **Specifics:** CoT reasoning improves accuracy by ~7–10% in evaluation benchmarks.

*   **Finding:** Content safety scoring utilizes specialized benchmarks and models (e.g., Llama Guard 3, WildGuard, ShieldGemma, SALAD-Bench) to score across dimensions like Toxicity, PII Leakage, Hate Speech, and Jailbreak Vulnerability using binary pass/fail checks.
    *   **Source URL:** https://github.com/promptfoo/promptfoo
    *   **Date:** Undated
    *   **Confidence:** HIGH (Official repository)
    *   **Specifics:** Tools like promptfoo provide specific `llm-rubric` assertions to define and automate safety criteria evaluations.

*   **Finding:** Evaluators must mitigate LLM biases, specifically "Self-Preference Bias" (where models like GPT-4 favor their own outputs) and "Verbosity Bias" (favoring longer responses).
    *   **Source URL:** https://wandb.ai/
    *   **Date:** Undated
    *   **Confidence:** MEDIUM (Technical blog/Platform docs)
    *   **Specifics:** Mitigation strategies include using an ensemble of different models as judges (e.g., GPT-4o + Claude 3.5 Sonnet) and strictly instructing the judge to ignore length.

#### 3. Handling multi-format output (text, images, carousels) from a single content idea
*   **Finding:** Production systems utilize a "Modular Content Architecture" where a single idea is processed by an LLM into a structured JSON manifest (extracting themes, hooks, data points) rather than direct text generation. This JSON acts as the source of truth for downstream format-specific agents.
    *   **Source URL:** https://www.optimizely.com/
    *   **Date:** Undated
    *   **Confidence:** MEDIUM (Industry vendor blog)

*   **Finding:** Multi-format rendering in production often avoids direct AI image generation for text-heavy assets (like carousels), instead relying on JSON-to-Visual Rendering. AI generates JSON data which is rendered via HTML/CSS templates (using tools like Puppeteer or Satori) to ensure pixel-perfect typography and brand alignment.
    *   **Source URL:** https://www.reddit.com/r/MachineLearning/ (Discussions on production pipelines)
    *   **Date:** Undated
