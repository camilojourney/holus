1. DSPy — PROMPT OPTIMIZATION FRAMEWORK
================================================================================

CURRENT VERSION: DSPy v2.5
MATURITY: Production-ready. Originated at Stanford NLP. Active development.
LICENSE: MIT
REPO: https://github.com/stanfordnlp/dspy

CORE ABSTRACTIONS:

a) Signatures
   - Define input/output behavior as typed declarations (not prompt strings)
   - Can be a short string like "question -> answer" or class-based with field descriptions
   - DSPy infers the prompting implementation from the signature
   - Isolates interface from implementation — enables automatic optimization
   CLAIM: Signatures replace hand-written prompts with declarative I/O specs
   SOURCE: https://dspy.ai/learn/programming/signatures/
   CONFIDENCE: HIGH

b) Modules
   - Building blocks that wrap LM calls with specific prompting strategies
   - Built-in modules:
     * dspy.Predict — basic LM invocation with a signature
     * dspy.ChainOfThought — adds reasoning step before output
     * dspy.ReAct — agent with tool use and reasoning loops
     * dspy.ProgramOfThought — code generation and execution
   - Modules are composable: you build programs by nesting modules
   CLAIM: Modules abstract prompting techniques (CoT, ReAct, etc.) into reusable components
   SOURCE: https://dspy.ai/ , https://deepwiki.com/stanfordnlp/dspy
   CONFIDENCE: HIGH

c) Optimizers (formerly Teleprompters)
   - Automatically tune prompts and weights to maximize user-defined metrics
   - Key optimizers:
     * BootstrapFewShot — generates traces, filters by metric, uses as few-shot examples
     * COPRO — optimizes instruction text
     * MIPROv2 — jointly optimizes both instructions AND few-shot examples
       Uses Bayesian Optimization for efficient search
       Data-aware and demonstration-aware instruction generation
       Uses minibatching for efficiency
   CLAIM: MIPROv2 achieves 15-30% performance improvements over manually crafted prompts on complex reasoning tasks
   SOURCE: https://dspy.ai/learn/optimization/optimizers/ , https://dspy.ai/api/optimizers/MIPROv2/
   CONFIDENCE: MEDIUM (benchmark-dependent, informal runs cited)

d) Assertions
   - Runtime constraints that validate LM outputs
   - Can trigger retries with feedback when assertions fail

NOTABLE RESULTS:
   - HotPotQA: ReAct score raised from 24% to 51% by teaching gpt-4o-mini task specifics
   - MIPROv2 shown to outperform manual prompt engineering across multiple benchmarks
   CLAIM: DSPy optimizers consistently outperform hand-tuned prompts on standard benchmarks
   SOURCE: https://dspy.ai/ , https://towardsdatascience.com/systematic-llm-prompt-engineering-using-dspy-optimization/
   CONFIDENCE: MEDIUM (results vary by task and model)

INTEGRATION EFFORT: Medium. Requires rethinking prompt design as signatures/modules.
Not a drop-in replacement — it's a different programming paradigm.

2. LANGSMITH — EVALUATION PLATFORM
================================================================================

VENDOR: LangChain (same team)
TYPE: Managed SaaS (cloud-hosted)
URL: https://www.langchain.com/langsmith/evaluation

EVALUATION CAPABILITIES:

a) Offline (Dataset-Based) Evaluation
   - Run against curated datasets during development
   - Acts as unit tests for LLM applications
   - Catch regressions before deployment
   CLAIM: Offline evaluation runs against curated datasets to catch regressions pre-deployment
   SOURCE: https://docs.langchain.com/langsmith/evaluation
   CONFIDENCE: HIGH

b) Online Evaluation
   - Scores real-world production traffic in real-time
   - Detects quality drift in production
   CLAIM: Online evaluation scores production traffic in real-time for quality drift detection
   SOURCE: https://www.langchain.com/langsmith/evaluation
   CONFIDENCE: HIGH

c) Annotation Queues
   - Flag production runs for human review
   - Assign to subject-matter experts with predefined rubrics
   - Human feedback calibrates automated evaluators
   - Improves prompts and augments datasets with high-quality test cases
   CLAIM: Annotation queues enable scalable human-in-the-loop review with predefined rubrics
   SOURCE: https://changelog.langchain.com/announcements/run-evaluators-in-the-langsmith-ui
   CONFIDENCE: HIGH

d) Custom Evaluators
   - Write in Python or TypeScript with arbitrary business logic
   - Run in LangSmith Playground across datasets (no coding required for UI-based ones)
   - Evaluator types: heuristic checks, LLM-as-judge, pairwise comparisons, human
   CLAIM: Custom evaluators support Python/TypeScript with arbitrary business logic, including no-code UI evaluators
   SOURCE: https://changelog.langchain.com/announcements/custom-code-evaluators-in-langsmith
   CONFIDENCE: HIGH

e) Experiments
   - Compare prompt versions side-by-side
   - Track metrics across iterations
   - Multi-turn evaluation for full agent conversations

PRICING (2026):
   - Developer (Free): 5K traces/month, 1 seat, 1 workspace, 14-day retention
   - Plus: $39/seat/month, 100K traces, 400-day retention, overage ~$0.50/1K traces
   - Enterprise: Custom pricing, SSO, dedicated support, custom retention
   CLAIM: LangSmith free tier limited to 5K traces; Plus at $39/seat/month
   SOURCE: https://www.langchain.com/pricing , https://checkthat.ai/brands/langsmith/pricing
   CONFIDENCE: HIGH

INTEGRATION EFFORT: Low if already using LangChain/LangGraph. Higher for custom stacks.
LOCK-IN RISK: Moderate — tightly coupled with LangChain ecosystem.

4. DEEPEVAL — TEST-DRIVEN LLM EVALUATION
================================================================================

TYPE: Open-source framework + optional cloud platform (Confident AI)
LICENSE: Apache-2.0
REPO: https://github.com/confident-ai/deepeval
URL: https://deepeval.com/

CORE METRICS:

a) G-Eval
   - LLM-as-a-judge with Chain-of-Thought (CoT) for ANY custom criteria
   - Most versatile metric — evaluates almost any use case with human-like accuracy
   - Based on the G-Eval research paper
   CLAIM: G-Eval achieves human-like accuracy for custom evaluation criteria using CoT
   SOURCE: https://deepeval.com/docs/metrics-llm-evals
   CONFIDENCE: MEDIUM (depends on judge model quality)

b) Hallucination Metric
   - Formula: Hallucination = Number of Contradicted Contexts / Total Number of Contexts
   - Uses LLM to check each context against actual_output for contradictions
   CLAIM: Hallucination metric measures contradiction rate between output and provided contexts
   SOURCE: https://deepeval.com/docs/metrics-hallucination
   CONFIDENCE: HIGH

c) Faithfulness Metric
   - LLM-as-a-judge measures if output factually aligns with retrieval_context
   - Evaluates RAG pipeline generator quality
   CLAIM: Faithfulness metric evaluates factual alignment between output and retrieval context
   SOURCE: https://deepeval.com/docs/metrics-faithfulness
   CONFIDENCE: HIGH

d) Answer Relevancy
   - Measures how relevant the answer is to the question
   - Part of the RAG evaluation triad

e) RAG Triad (5 metrics)
   - Answer relevancy, faithfulness, contextual relevancy, contextual recall, contextual precision
   - Each maps to a specific RAG hyperparameter
   CLAIM: DeepEval's 5-metric RAG triad maps each metric to specific RAG hyperparameters
   SOURCE: https://www.braintrust.dev/articles/deepeval-alternatives-2026
   CONFIDENCE: HIGH

TEST-DRIVEN APPROACH:
   - pytest-compatible: run LLM evaluations in CI/CD like regular unit tests
   - `deepeval test run` command for local and CI execution
   - 30+ built-in metrics
   CLAIM: DeepEval wraps LLM metrics into pytest-compatible tests for CI/CD integration
   SOURCE: https://github.com/confident-ai/deepeval , https://google.github.io/litmus/evaluate-deepeval
   CONFIDENCE: HIGH

CONFIDENT AI PLATFORM PRICING (2026):
   - Free: $0, 5 test runs/week, 10K traces/month, 1-week retention
   - Starter: $19.99/user/month, 20K traces/month, 1-month retention
   - Premium: $79.99/user/month, 100K traces/month, 3-month retention, alerting
   - Team/Enterprise: Custom, HIPAA/SOC2/SSO, AI red teaming
   CLAIM: DeepEval open-source is fully free; Confident AI cloud starts at $19.99/user/month
   SOURCE: https://www.confident-ai.com/pricing
   CONFIDENCE: HIGH

INTEGRATION EFFORT: Very low. pip install deepeval, write test cases, run.

--- 6a. RAGAS (Retrieval Augmented Generation Assessment) ---

TYPE: Open-source framework for RAG evaluation
PAPER: https://arxiv.org/abs/2309.15217
DOCS: https://docs.ragas.io/

KEY METRICS:
   - Context Precision: ranks relevant chunks higher in retrieved context
   - Context Recall: measures if all relevant info was retrieved (requires ground truth)
   - Faithfulness: factual consistency of answer with context
   - Answer Relevancy: relevance of answer to question
   - Noise Sensitivity: robustness to irrelevant context

2026 UPDATES:
   - Now supports agentic workflow metrics, tool use evaluation, SQL evaluation
   - Multimodal extensions: Multimodal Faithfulness, etc.
   CLAIM: Ragas now supports agentic workflows, tool use, SQL, and multimodal evaluation
   SOURCE: https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/
   CONFIDENCE: MEDIUM

INTEGRATION: Works with Langfuse, LangSmith, and standalone
BEST FOR: RAG-specific evaluation pipelines

STRENGTHS BY TOOL FOR MULTI-AGENT CONTENT:

DSPy:
   + Best for: Automatically optimizing prompts for each specialist agent
   + Unique: Programmatic prompt optimization replaces manual prompt engineering
   - Weakness: No observability, no production monitoring, no tracing
   - Not an evaluation platform — it's an optimization framework

LangSmith:
   + Best for: Teams already on LangChain/LangGraph
   + Strong annotation queues for content review workflows
   - Weakness: Vendor lock-in to LangChain ecosystem
   - Limited multi-agent tracing compared to Braintrust

Braintrust:
   + Best for: Production quality gates with CI/CD blocking
   + One-click trace-to-test-case conversion
   + Best free tier (1M spans)
   - Weakness: Proprietary, no self-hosting
   - $249/month Pro plan jumps quickly

DeepEval:
   + Best for: Testing content quality with 30+ metrics in CI
   + G-Eval handles arbitrary content quality criteria
   + Hallucination + faithfulness metrics critical for content generation
   + Fully open-source, runs locally
   - Weakness: Limited observability/tracing for production
   - Cloud platform (Confident AI) needed for dashboards

Langfuse:
   + Best for: Self-hosted observability + evaluation (already in Holus stack)
   + Prompt management with version comparison
   + Open source, no vendor lock-in
   + Integrates with Ragas for RAG metrics
   - Weakness: Evaluation features less mature than Braintrust/DeepEval
   - Self-hosting operational burden

Phoenix/Arize:
   + Best for: OTel-native, vendor-agnostic observability
   + Broad framework support including Claude Agent SDK
   - Weakness: Evaluation less developed than specialized tools

8. RECOMMENDATIONS FOR HOLUS (MULTI-AGENT CONTENT GENERATION)
================================================================================

RECOMMENDED STACK (layered approach):

Layer 1 — OBSERVABILITY: Langfuse (already in Holus stack)
   - Keep Langfuse for tracing, cost tracking, prompt management
   - Self-hosted = data sovereignty, no vendor lock-in
   - Add per-agent trace tagging for specialist performance tracking

Layer 2 — EVALUATION METRICS: DeepEval
   - Use DeepEval's G-Eval for content quality scoring (custom criteria per content type)
   - Hallucination + Faithfulness metrics for factual content
   - Answer Relevancy for relevance to brief/topic
   - pytest integration = runs in CI, catches regressions
   - Free, open-source, no cloud dependency

Layer 3 — PROMPT OPTIMIZATION: DSPy (experimental)
   - Use MIPROv2 to optimize specialist agent prompts
   - Define signatures for each content type
   - Run optimization against quality metrics from DeepEval
   - Higher integration effort but highest optimization ceiling

Layer 4 — RED TEAMING (optional): Promptfoo
   - Scan content generation for safety issues
   - Test for prompt injection in user-facing content workflows

WHY NOT:
   - LangSmith: Holus doesn't use LangChain. Lock-in not worth it.
   - Braintrust: Excellent but proprietary. $249/month Pro is expensive for
     features Langfuse + DeepEval provide at $0.
   - Phoenix: Good but overlaps with Langfuse (already in stack).

INTEGRATION PATTERN:
   1. Langfuse traces every agent call (already wired)
   2. DeepEval runs as eval_gate.py replacement/supplement
      - Content quality gate: G-Eval with custom rubric
      - Factual gate: Hallucination + Faithfulness
      - Relevance gate: Answer Relevancy
   3. DSPy optimizes prompts offline against DeepEval metrics
   4. Langfuse prompt management deploys optimized prompts

ESTIMATED EFFORT:
   - DeepEval integration: 1-2 days (pip install, write test cases, wire to CI)
   - DSPy integration: 3-5 days (refactor agent prompts to signatures, set up optimization)
   - Langfuse already integrated
   - Total: ~1 week for Layer 1+2, +1 week for Layer 3
