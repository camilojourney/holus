# LinkedIn Creator Research Blueprint

**Purpose:** Standardized framework for analyzing any LinkedIn creator in our niche. Every profile in this directory MUST follow this blueprint. Consistency across profiles enables pattern detection.

**Updated:** 2026-03-17

---

## How to Use This Blueprint

1. For each new reference person, create a folder: `reference/linkedin/[Full Name]/profile.md`
2. Fill every section below. Mark unavailable data as `[NOT AVAILABLE]` with reason
3. After 5+ profiles are complete, update `patterns.md` with cross-person analysis
4. Review quarterly — people change roles, strategies evolve

---

## Data Collection Toolkit

| Tool | URL | What It Gets | Cost |
|------|-----|-------------|------|
| **Favikon** | favikon.com | Influence score, ranking, growth rate, engagement rate, posting frequency | Free tier available |
| **Taplio** | taplio.com/lookup/[handle] | Engagement score, top posts, activity analysis | Free lookup |
| **Google Cache** | `site:linkedin.com/posts/[handle]` | Indexed public posts (text only, no images) | Free |
| **Apify LinkedIn Scraper** | apify.com | Full post history: text, reactions, comments, timestamps | ~$49/mo |
| **PhantomBuster** | phantombuster.com | Automated profile + post extraction | $59/mo |
| **LinkedIn (manual)** | linkedin.com/in/[handle]/recent-activity/ | Last ~20 posts, visual inspection | Free (login required) |
| **Wayback Machine** | web.archive.org | Historical snapshots of public profiles | Free |

**What's NOT obtainable externally:** Views/impressions (only visible to post author), full image/video downloads, DM strategy, revenue from partnerships.
