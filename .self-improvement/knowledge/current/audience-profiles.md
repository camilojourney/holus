## Primary Audiences by Product

### Pilaster — ComfyUI Artists & AI Creators

| Field | Value |
|-------|-------|
| Who | AI artists, ComfyUI power users, Stable Diffusion community |
| Pain points | Losing good workflows, can't compare versions, no memory of what worked |
| Content they want | Tutorials, workflow showcases, before/after comparisons, tips & tricks |
| Platforms they use | TikTok (visual demos), LinkedIn (professional), Twitter/X (community), YouTube (learning) |
| Language | English primary, some Spanish |
| Tone | Technical but accessible. Show don't tell. Visual-first. |
| Content triggers | New ComfyUI updates, workflow techniques, style discoveries |
| Competitors | CivitAI, PromptHero, ComfyUI Manager |

### genpeli — Content Creators & Video Editors

| Field | Value |
|-------|-------|
| Who | YouTubers, social media managers, small agencies, solo creators |
| Pain points | Video editing is slow, expensive tools, repetitive tasks |
| Content they want | Demos, case studies, time comparisons, workflow automation tips |
| Platforms they use | LinkedIn (professional), Instagram (visual), YouTube (discovery) |
| Language | English primary, Spanish secondary |
| Tone | Professional but energetic. Results-focused. "Look what you can do." |
| Content triggers | New features, comparison with competitors, creator success stories |
| Competitors | Descript, Runway, Kapwing, CapCut Pro |

### invoz — Developers & Audio Engineers

| Field | Value |
|-------|-------|
| Who | Backend developers, ML engineers, audio processing devs |
| Pain points | Audio ML is hard, bad documentation, no good APIs |
| Content they want | Technical posts, API documentation, code examples, architecture deep-dives |
| Platforms they use | LinkedIn (professional), Twitter/X (tech community), Dev.to, Hacker News |
| Language | English |
| Tone | Technical, precise, developer-to-developer. Code-first. |
| Content triggers | New API endpoints, benchmarks, integration guides, ML paper breakdowns |
| Competitors | AssemblyAI, Deepgram, Whisper API wrappers |

## Cross-Product Audience Insights

### Overlap Areas

- **AI/ML enthusiasts** consume content about all three products
- **Solo founders / indie hackers** are interested in automation tools (genpeli + invoz)
- **Creative professionals** use both Pilaster and genpeli

### Content That Works Across Products

- "Behind the scenes of building AI tools" — founder journey content
- "AI tools that save me X hours/week" — productivity angle
- "How I built X with AI" — builder community resonates

## Audience Engagement Patterns

### What Gets High Engagement

| Pattern | Why | Example |
|---------|-----|---------|
| Before/after comparisons | Visual proof of value | "Workflow v1 vs v5 after Pilaster" |
| Time-lapse of AI creating | Mesmerizing, shareable | "Watch genpeli edit this video in 30s" |
| Hot takes on AI trends | Drives discussion | "Why prompt engineering is dead" |
| Tutorial threads | Bookmark-worthy | "5 ComfyUI tricks you're missing" |
| Real numbers / metrics | Credibility | "This post got 10K views. Here's why." |

### What Gets Low Engagement

| Pattern | Why |
|---------|-----|
| Pure product announcements | Feels like an ad |
| Generic AI hype | Oversaturated, no unique angle |
| Long text without visuals | Skipped in feed |
| Overly technical without context | Too niche for most followers |
