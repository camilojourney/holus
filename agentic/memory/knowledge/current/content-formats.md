## Template: LinkedIn Post

```
[Hook — 1 line that stops scrolling]

[2-3 lines expanding on the hook]

[Key insight or value — the "meat"]

[Personal take or lesson learned]

[CTA — question or call to action]

#hashtag1 #hashtag2 #hashtag3
```

**Rules:**
- Hook must be compelling enough to click "see more"
- Use line breaks liberally (LinkedIn rewards readability)
- Max 3 hashtags (more looks spammy)
- No external links in the main post (kills reach). Put links in comments.
- Emoji: 0-2 max, never at the start

## Template: Twitter/X Thread

```
Tweet 1 (Hook):
[Bold claim or question that demands attention]

Tweet 2-N (Value):
[One clear point per tweet]
[Use numbers, bullet points, or visuals]

Final Tweet (CTA):
[Summary + ask for RT/follow]
[Link if needed goes here, not in hook]
```

**Rules:**
- Each tweet must stand alone (people see individual tweets in feeds)
- Hook tweet: no links, no hashtags, just the grab
- Use emoji bullets (→, •, ✓) for scanability
- End with "If you found this useful, RT tweet 1"

## Template: TikTok Video Script

```
[0-3s] HOOK: "Here's something most people don't know about [topic]"
[3-15s] SETUP: Show the problem or current state
[15-45s] PAYOFF: Show the solution/tutorial/demo
[45-60s] CTA: "Follow for more [niche] content"
```

**Rules:**
- First 3 seconds decide everything
- On-screen text is mandatory (many watch muted)
- Show, don't tell
- Vertical 9:16 only
- Trending sounds boost discovery (but not required for tutorial content)

---

## Template: Instagram Carousel (Slides)

```
Slide 1: Hook headline (bold, large text)
Slide 2: Problem statement
Slide 3-8: Solution steps (one per slide)
Slide 9: Summary / key takeaway
Slide 10: CTA + follow
```

**Rules:**
- Design must be consistent (brand colors, fonts)
- Each slide must be readable in 3 seconds
- Save-worthy content gets algorithmic push
- Caption: detailed explanation of the carousel content

product icon in corner, high contrast readable text,
modern flat design, brand color accent
